2. Why do developers use branches

A: developers use branches for many things that may include fixing typos, adding a feature, or even experimenting, all with the purpose of not messing with main or ruining it in any way, we also see this with branch names like bug fix or experimental as well. 

3. What is GIT? What is Github? How does Git and Github work together?

A: GIT is kinda like an open sourced distribution system, kinda as a way to make it easier for developers to work together on things and track each other's work, and Git hub was a way to make it easier for people to use GIT, without being as tech-savvy. They both work together in order to make the developer's lives a LOT easier and make it so even a kid like me could learn to code or even just the basics.

4. What is wrong with the format command sequence? What should be the correct Command sequence?

git commit -m "saving work"
git add .
git push

A: This command sequence is incorrect as they swapped the places of the git add . and the git commit -m so the correct sequence should be something like this:

git add .
git commit -m "saving work"
git push

(You can also think of this as adding things to the box, commit or packaging the box prepping it for delivery and then pushing or sending it out to be shipped to the customer.)
